# 🎨 ChatterHub Color Scheme

## Updated Colors (Lighter & Vibrant)

### Primary (Purple)
- **Light**: `#8b7fc7` - Lighter purple for hover states and accents
- **Default**: `#6b5fb0` - Brighter purple for primary actions and branding
- **Dark**: `#4a3f8a` - Medium purple for active states

### Secondary (Pink)
- **Light**: `#ff9ec4` - Lighter pink for subtle highlights
- **Default**: `#ff6ba9` - Brighter pink for secondary actions
- **Dark**: `#e94f8f` - Medium pink for emphasis

## Color Usage

### Gradients
```css
/* Primary gradient */
bg-gradient-to-r from-primary to-secondary

/* Light gradient */
bg-gradient-to-br from-primary-light to-secondary-light

/* Dark gradient */
bg-gradient-to-r from-primary-dark to-secondary-dark
```

### Buttons
- **Primary Button**: Purple background with hover effects
- **Secondary Button**: Pink background
- **Gradient Button**: Purple to pink gradient

### Text
- **Primary Text**: Purple for links and important text
- **Secondary Text**: Pink for highlights and accents

### Backgrounds
- **Primary BG**: Light purple backgrounds for cards
- **Secondary BG**: Light pink for notifications
